# Задачник

Окремий Next.js-застосунок для особистих, сімейних та робочих задач. Він використовує той самий проєкт Supabase, що й «Сімейні покупки», але має незалежний запуск і окреме розгортання у Vercel.

## Локальний запуск

1. Скопіюйте `.env.example` у `.env.local` і внесіть публічні параметри того самого Supabase-проєкту. Значення з іншого застосунку не дублюються в Git і не переносяться автоматично.
2. З кореня репозиторію виконайте `npm --prefix task-manager run dev`.
3. Відкрийте адресу, яку покаже Next.js, і перейдіть до `/tasks`.

## Окреме розгортання

У Vercel створіть **новий** проєкт з цього самого GitHub-репозиторію та вкажіть Root Directory: `task-manager`. Додайте ті самі значення `NEXT_PUBLIC_SUPABASE_URL` і `NEXT_PUBLIC_SUPABASE_ANON_KEY`, що має застосунок «Сімейні покупки».

На цьому етапі спільний модуль задач лишається в цьому репозиторії, а інтерфейси та розгортання вже розділені. Це дозволяє запустити Задачник без копіювання даних і без ризику для покупок.
