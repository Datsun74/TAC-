# Спільний безпечний доступ

## Як це працює

- Вхід відбувається за одноразовим посиланням (Magic Link) на email. Паролів немає.
- Email використовується лише Supabase Auth. У таблиці покупок і в інтерфейсі він не відображається.
- Для кожного дозволеного користувача зберігається лише видиме ім’я, наприклад `Сергій`.
- Таблиця `family_members` є закритим списком доступу. Тільки її активні члени можуть читати й змінювати `shopping_items`.
- Людина, яка увійшла, але ще не є у списку, не бачить покупки. Вона отримує лише свій код для одноразового підтвердження.

## Перший запуск

1. У Supabase SQL Editor запустіть файл `supabase/family-access.sql`.
2. У **Authentication → URL Configuration** встановіть `Site URL`: `http://localhost:3000` і додайте до **Redirect URLs**: `http://localhost:3000/auth/confirm`.
3. Шаблони листів змінювати не потрібно: застосунок передає безпечне посилання повернення для стандартного листа Supabase.
4. Відкрийте `http://localhost:3000`, введіть свій email і відкрийте лист на цьому ж комп’ютері у браузері.
5. На сторінці «Доступ очікує» скопіюйте код. У SQL Editor виконайте, підставивши цей код замість `ВАШ_UUID`:

   ```sql
   insert into public.family_members (user_id, display_name)
   values ('ВАШ_UUID', 'Сергій')
   on conflict (user_id)
   do update set display_name = excluded.display_name, is_active = true;
   ```

6. Оновіть сторінку застосунку. У верхній частині буде показано `Сергій`, а список стане доступним.

## Додавання іншої людини

Нова людина входить за своїм email, передає власний код зі сторінки «Доступ очікує», а відповідальна особа додає його тим самим SQL-запитом із потрібним видимим ім’ям. Email інших членів сім’ї не відображається.

Після того як додані всі потрібні люди, у **Authentication → General Configuration** вимкніть **Allow new users to sign up**. Уже додані члени сім’ї й надалі зможуть входити за Magic Link, а нові облікові записи не створюватимуться.
